# 🚀 Actividad Web: Calculadora y Validación de Formularios

Este repositorio contiene dos proyectos desarrollados como parte de mi proceso de aprendizaje en Desarrollo Web. El objetivo principal fue poner en práctica el manejo de eventos, la delegación de eventos y la validación dinámica en tiempo real utilizando JavaScript.

## 📂 Proyectos incluidos

### 1. Calculadora Interactiva 🧮
Una calculadora básica construida con HTML, CSS y JavaScript.
- **Características:** Manejo de operaciones básicas (suma, resta, multiplicación, división), botón de limpiar (C), manejo de errores y evaluación de operaciones.
- **Concepto clave:** Implementación de **Delegación de Eventos**. Se utiliza un único `addEventListener` en el contenedor principal para capturar los clics de todos los botones, haciendo el código más eficiente.
- **Ruta:** `/calculadora`

### 2. Validación Dinámica de Formulario 📝
Un formulario de registro de usuarios que valida los datos en tiempo real mientras el usuario escribe.
- **Características:** Validación de nombre (mín. 3 letras), correo (con @ y .), edad (mayor a 18), contraseña (mín. 8 caracteres) y confirmación. Retroalimentación visual (verde/rojo) y mensajes de error/éxito.
- **Concepto clave:** Uso de eventos `input` para validación en tiempo real y `submit` para controlar el envío. Uso de funciones independientes para cada campo.
- **Ruta:** `/formulario`

## 🛠️ Tecnologías utilizadas
- HTML5
- CSS3
- JavaScript (Vanilla)

## 🚀 Cómo probar los proyectos
No necesitas instalar nada. Simplemente puedes descargar este repositorio o clonarlo, y abrir el archivo `index.html` (ubicado dentro de la carpeta `calculadora` o `formulario`) en tu navegador web favorito.
